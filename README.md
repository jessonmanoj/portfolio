# Jesson Manoj — Portfolio

A personal portfolio for Jesson Manoj, an MCA student, aspiring software developer, web developer, and digital marketing professional.

## Live Website

https://jessonmanoj.github.io/portfolio/

## Technologies

- HTML
- CSS
- JavaScript

The portfolio also presents Jesson's current experience with HTML, CSS, JavaScript, Python, and PHP.

## Features

- Responsive desktop and mobile design
- Light and dark themes with saved preference
- Animated hero, scrolling sections, and technology marquee
- Profile and creative personal-branding imagery
- Project filtering and editable portfolio data
- Contact form UI with client-side validation
- Accessibility and reduced-motion support

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deployment

This is a static website designed for GitHub Pages. In the repository settings, choose **Pages** → **Deploy from a branch** → `main` → `/ (root)`.

## Important assets

- `assets/images/profile.jpg`
- `assets/images/jesson_creative.png`
- Place the CV at `assets/Jesson-Manoj-Resume.pdf` before publishing so the Download CV button can work.
